## 1. 软件简介

### 1.1 它解决什么问题

学校要求学生每天完成"光盘行动"打卡，规则是**每日最多 3 次、每次间隔至少 2 小时**，打卡入口是微信小程序「光盘打卡」。这条规则真正的难点不是打卡本身，而是：

- 三次时间被上次打卡的实际时间"顶着走"，晚打一次，后面全部顺延，靠记性根本算不准；
- 饭点人不在电脑前，或者人在电脑前但注意力在别处，闹钟响了也会被划掉；
- 打完卡又忘了自己打没打、上次几点打的。

这个工具把这三件事接过来：**算下次能打的时间、在你在电脑前的时候叫你、把你每次打卡记下来**。

### 1.2 它做什么，不做什么

| 会做 | 不会做 |
|---|---|
| 记录每天打了第几次、上次几点打的 | ❌ 不会替你在小程序里点打卡 |
| 到点用右下角卡片 + 提示音提醒你 | ❌ 不会抓包调用小程序的私有接口 |
| 点按钮时校验间隔，不够就拦下并告诉你还差多久 | ❌ 不会上传任何数据到网络 |
| 提供"最晚几点必须打下一次"的安全线 | ❌ 不会修改你的系统设置（除了一条开机自启项） |
| 导出手机日历做兜底提醒 | |

> **关于"自动打卡"**：小程序走的是 `api.clearplate.org.cn` 的私有接口，需要抓包拿 `x-token`，并复用历史已上传的餐盘图路径。技术上能跑通，但本质是伪造就餐记录，且 token 会随登录态失效、接口随时改版。**本项目故意不做这件事。**

### 1.3 三个核心设计（理解了这三条，其余都是细节）

1. **提醒不按固定钟点，按"你今天第一次碰电脑"起算。**
   每天第一次检测到键鼠输入的时刻记为 T0，两小时后到点。之后每弹一次，从弹出时刻再数两小时。这样不会出现"设了 12:00 的闹钟，但你 12:40 才打卡，14:00 的提醒完全无效"的情况。

2. **到点那一刻先看你在不在。**
   只有最近 60 秒内动过键鼠才弹窗；人不在就压着，等你回来动一下鼠标立刻补弹。看视频、读长文档连续不动，也算"人不在"（阈值可调）。

3. **次数、下次时间这类派生值一律不落盘，每次现算。**
   磁盘上只存"打卡记录 + 设置"两份原始数据，所有数字都由它们实时推导，杜绝"时间改了但计数没跟上"的脏状态。

## 2. 安装与环境配置

### 2.1 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809 及以上 / Windows 11（64 位） |
| 运行时 | **不需要**预装 .NET（程序已自包含） |
| 磁盘空间 | 约 50 MB（程序本体约 46 MB + 数据） |
| 权限 | 普通用户权限即可（开机自启写在当前用户注册表项，不需要管理员） |
| 网络 | 安装与运行都不需要联网 |

### 2.2 下载与放置

1. 打开 **[Release 页面](https://github.com/LXJ6668848/Clean-Plate-Campaign/releases/latest)**，在 `Assets` 里点 `光盘打卡提醒.exe` 下载（也可以直接取仓库里的 `release/光盘打卡提醒.exe`）；
2. **把它放到一个固定目录**，例如 `D:\Tools\光盘打卡提醒\`；
3. 建议核对文件完整性（可选，对应 v1.1.0）：

```
文件大小：48,073,597 字节（约 45.8 MiB）
SHA256  ：FC5BBE60AAE8837332EAEA7E5A7978DD4F35686A901E0963694E5A51E4AF9171
```

在 PowerShell 里核对：

```powershell
Get-FileHash "D:\Tools\光盘打卡提醒\光盘打卡提醒.exe" -Algorithm SHA256
```

> ⚠️ **不要放在桌面或下载目录**。程序会把"当前 exe 路径"写进开机自启项，一旦你移动或删除 exe，自启就会失效并留下一个指向空路径的启动项。

### 2.3 首次启动

1. 双击 `光盘打卡提醒.exe`；
2. 如果 Windows 弹出"Windows 已保护你的电脑"（SmartScreen），点 **更多信息 → 仍要运行**（这是未做代码签名的小众程序的正常提示，不是病毒警告）；
3. 主面板会直接打开，同时任务栏右下角出现一个圆形托盘图标。

### 2.4 通知权限（这一步不做，提醒可能静默消失）

程序用的是 Windows 原生通知 + 自带卡片窗口，但系统层的"专注助手/勿扰"仍可能拦截：

| 系统 | 设置路径 |
|---|---|
| Windows 11 | 设置 → 系统 → 通知 → 找到「光盘打卡提醒」→ 打开通知；再把"专注助手"设为"仅闹钟"或关闭 |
| Windows 10 | 设置 → 系统 → 通知和操作 → 打开通知；关闭"专注助手" |

程序自己弹出的右下角卡片**不受专注助手影响**，会正常出现；被拦截的主要是托盘气泡。因此建议卡片和气泡同时开启（默认即如此）。

### 2.5 把托盘图标固定出来

新装的程序图标通常被 Windows 折叠进任务栏右下角的 `^` 里，导致"以为它没启动"：

1. 点任务栏右下角的 `^`；
2. 把里面的圆形图标**拖到外面**（放到任务栏可见区域），以后就能一眼看到状态颜色。

### 2.6 开机自启

首次运行会**自动开启**开机自启（注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\GuangPanCheckin`，值为 `"exe 路径" --autostart`）。

- 带 `--autostart` 启动时程序**安静待在托盘**，不弹主窗口；
- 想关掉：托盘右键 → 取消勾选「开机自动启动」，或设置页取消「开机自动启动」；
- 关掉后，每次开机需要手动双击一次 exe。

### 2.7 手机端兜底配置（可选，但强烈建议）

电脑负责算，手机负责响。食堂排队时你不在电脑前，这部分只能靠手机。

1. 托盘右键 → **同步到手机日历…**；
2. 程序生成 `%APPDATA%\GuangPanCheckin\guangpan.ics`，并弹出文件所在位置；
3. 用微信「文件传输助手」把这个 `.ics` 发到手机，点开选 **添加到日历**；
4. 导入后，手机每天会在你设定的"兜底时刻"响铃（默认 07:20 / 11:50 / 17:40）。

> 手机日历只能按**固定时刻**响，做不到"你一动鼠标才响"，所以它和电脑的节拍是两套独立机制，不按打卡次数绑定。改了兜底时刻要**重新导出一份，并在导入前先删掉旧日程**，否则会双份提醒。

### 2.8 打卡示意图（可选）

点提醒卡片上的「去打卡」会弹出一张示意图（默认是吃干净的碗筷照片），提醒你要拍什么样的餐盘。

- 换图：托盘右键 → 设置 → 「打卡示意图」→ **更换…**（支持 jpg / png / bmp，单张不超过 50 MB）；
- 程序把图片**复制**到 `%APPDATA%\GuangPanCheckin\assets\target.jpg`，原图之后被移动或删除都不影响；
- 点 **打开目录** 可以直接查看当前使用的文件。

## 3. 主要功能说明

### 3.1 主面板

双击托盘图标（或在托盘菜单选"打开面板"）即可打开。

| 元素 | 含义 |
|---|---|
| 今日进度 | 今天已打卡 x / 3，以及三个圆点的完成状态 |
| 上次打卡 | 最近一次打卡的具体时刻 |
| 倒计时 | 距离"下次最早可打卡"还有多久；已可打卡时显示提示语 |
| 安全线 | "最晚 20:00 前打下一次，才来得及完成今天的 3 次"；时间不够时变红，直接告诉你今天最多还能完成几次 |
| 计时起点（副标题） | 今天从几点开始算节拍，例如"今天从 08:12 开始计时" |
| 最近 5 天 | 每天的打卡次数与时刻 |
| 按钮 | 我已打卡 / 撤销上一条 / 设置 / 同步到手机 |

### 3.2 托盘图标的三色状态

| 颜色 | 含义 |
|---|---|
| 灰蓝 | 还没到下次可打卡时间，正在等间隔 |
| 黄 | 现在可以打卡 |
| 绿 | 今天已打满 3 次 |

鼠标悬停会显示文字提示；右键是快捷菜单。

### 3.3 提醒卡片

到点后右下角弹出小卡片（430×184，置顶但不抢焦点，可拖动，**120 秒无操作自动收起**——自动收起不算打卡）。

| 按钮 | 行为 |
|---|---|
| **去打卡**（绿色主按钮） | 关闭卡片，弹出打卡示意图窗口。**不算打卡**，也不消耗本轮提醒次数 |
| **我已打卡** | 记录一次打卡，关闭卡片 |
| 10 分钟后再提醒（底部小字） | 本轮暂停 10 分钟，之后重新提醒 |
| 今天不再提醒（底部小字） | 今天静默，明天 0 点恢复 |

**没处理会升级加催**：

| 阶段 | 触发 | 表现 |
|---|---|---|
| 第一次 | 到点 | 卡片 + 提示音 + 托盘气泡 |
| 第二次 | +10 分钟仍未处理 | 再弹一次 |
| 第三次 | +30 分钟仍未处理 | 最后一次，之后本轮彻底安静 |

升级提醒同样遵守"必须检测到你在操作"的门控，不会在无人值守时刷屏。

### 3.4 "有操作"的判定规则

程序调用 Windows 的 `GetLastInputInfo` 读取**全局最后输入时间**（键鼠、触摸板都算，不要求本程序窗口有焦点）。

| 情况 | 是否弹窗 |
|---|---|
| 到点，最近 60 秒内动过键鼠 | ✅ 立即弹 |
| 到点，但已空闲 60 秒以上 | ⏸ 不弹，记"待弹"标记；你下次动键鼠时立刻补弹 |
| 屏幕已锁定 | ⏸ 不弹；解锁后回到"到点即弹" |
| 已打满 3 次 / 手动静音 / 处于免打扰时段 | ❌ 不弹 |
| 电脑休眠中 | ❌ 不弹；唤醒后若已过点，动一下鼠标即补弹 |

阈值可在设置页「有操作判定（空闲秒数）」调整（默认 60 秒）。**如果你常连续看视频或读长文档、几分钟不碰键鼠**，建议调到 180～300 秒，否则提醒会一直被推迟到你下次碰鼠标。

### 3.5 打卡约束与安全线

| 学校规则 | 程序里的实现 |
|---|---|
| 每日最多 3 次 | 按自然日统计，**每天 0 点自动刷新** |
| 每次间隔 ≥ 2 小时 | 以"上次打卡实际时间 + 120 分钟"作为下次最早可打卡时间，点按钮时会二次校验并拦下 |
| 24 小时都能打 | 没有硬性截止，只把"24:00 前最后一次可打卡时间"显示出来当安全线 |

两个概念不要混：

- **下次最早可打卡** = 上次打卡时间 + 最小间隔（硬约束）；
- **提醒时间** = 当天首次操作起算的两小时节拍，且到点必须检测到你在操作。

### 3.6 撤销

打完卡 5 分钟内，主面板「撤销上一条」可用（按钮上会直接显示时刻，如"撤销 12:32 那条"）。点下去会二次确认，撤销的是**今天最后一条**记录。超过 5 分钟按钮变灰，防止误改历史。

### 3.7 「去打卡」与示意图窗口

点卡片上的「去打卡」→ 卡片关闭 → 右下角同位置弹出图片窗（宽 320，等比缩放到屏幕高度 80% 以内，可拖动）。

| 在图片窗里操作 | 结果 |
|---|---|
| 点「我已打卡」 | 记录一次打卡，两个窗口都关闭 |
| 点右上角 × 或「关闭」 | 只关图片窗，**不记打卡**，提醒节奏不变（该升级仍会升级） |
| 按 Esc | 同上 |
| 重复点卡片上的「去打卡」 | 只把已打开的图片窗置顶，不会叠出第二个窗口 |

### 3.8 设置项一览

托盘右键 → **设置…**

| 设置项 | 默认值 | 可调范围 | 说明 |
|---|---|---|---|
| 每日次数上限 | 3 | 1–5 | 学校规则改了不用改代码 |
| 最小间隔（分钟） | 120 | 30–360 | 影响"下次最早可打卡" |
| 有操作判定（空闲秒数） | 60 | 5–600 | 越小越"容易认为你不在" |
| 手机日历兜底时刻 | 07:20 / 11:50 / 17:40 | 最多 5 个，可留空 | 只影响导出的日历，不影响电脑弹窗 |
| 免打扰时段 | 23:00–07:00 | 任意 HH:mm | 该时段一律不弹 |
| 打卡示意图 | 已设置 | 可更换 | jpg / png / bmp，≤ 50 MB |
| 未确认时升级提醒 | +10 / +30 分钟 | 1–60 / 5–120 | 本轮最多响 3 次 |
| 提醒时播放提示音 | 开 | 开关 | |
| 弹出右下角提醒卡片 | 开 | 开关 | 关掉后只剩托盘气泡 |
| 同时发托盘气泡通知 | 开 | 开关 | |
| 跨天也受最小间隔限制 | 开 | 开关 | 关闭后"23:50 打过，次日 00:10 也能打" |
| 开机自动启动 | 开 | 开关 | |

### 3.9 命令行开关（进阶，日常用不到）

在命令行里执行：

| 参数 | 作用 |
|---|---|
| `--autostart` | 开机自启用，安静待在托盘不弹窗 |
| `--selftest` | 跑 53 条边界逻辑用例，结果写 `selftest.log` |
| `--uitest` | 跑 23 条界面交互用例（含真实鼠标点击「去打卡」），结果写 `uitest.log` |
| `--shot` | 生成三张界面截图到数据目录（排版自检用） |
| `--idle` | 打印当前空闲秒数，用于确认"有操作"判定是否正常 |
| `--ics` | 不开界面，直接重新导出手机日历 `guangpan.ics` |

## 4. 操作步骤

### 4.1 五分钟上手

1. **放置**：把 exe 放到 `D:\Tools\光盘打卡提醒\` 这类固定目录；
2. **启动**：双击运行，主面板出现即成功（托盘同时出现圆形图标）；
3. **固定图标**：点 `^`，把圆形图标拖到任务栏可见区域；
4. **核对设置**：右键托盘 → 设置，确认每日次数 = 3、间隔 = 120 分钟、免打扰时段符合你的作息；
5. **导手机日历（可选）**：右键托盘 → 同步到手机日历…，把 `.ics` 发到手机导入。

### 4.2 一天的完整流程

| 时间 | 你在做什么 | 程序做什么 |
|---|---|---|
| 08:12 | 开机，敲了第一下键盘 | 记录计时起点 T0 = 08:12 |
| 10:12 | 到点，你正在用电脑 | 弹出提醒卡片（第 1 次） |
| 10:15 | 去食堂，在小程序里打完卡 | 回面板点「我已打卡」，记录 10:15 |
| 10:15 | — | 算出下次最早可打卡 = 12:15，节拍下一轮 = 12:12，取 12:15 |
| 12:15 | 到点，人不在电脑前 | **不弹**，标记待弹 |
| 12:40 | 回到电脑前动了下鼠标 | 立刻补弹 |
| 12:45 | 打完卡，点「我已打卡」 | 记录 12:45，下次最早 14:45 |
| 14:45 | 到点且你在操作 | 弹第 3 次 |
| 15:00 | 打满 3 次 | 托盘图标变绿，当天不再提醒 |
| 次日 00:00 | — | 计数归零、计时起点清空，等新一天第一次操作 |

### 4.3 关闭与退出

| 操作 | 结果 |
|---|---|
| 点窗口右上角 × | **收进托盘**，提醒照常跑 |
| 再次双击 exe | 唤起已在运行的那个实例（不会重复开进程） |
| 托盘右键 → 退出 | 真正退出，不再提醒 |

### 4.4 换电脑 / 重装迁移

1. 在旧机器上完全退出程序；
2. 复制整个 `%APPDATA%\GuangPanCheckin\` 目录（含 `records.json`、`settings.json`、`assets\`）到新机器相同位置；
3. 到新机器上运行一次 exe，重新开启开机自启（路径变了，需要重写）。

### 4.5 卸载

1. 托盘右键 → 取消勾选「开机自动启动」→ 退出；
2. 删除 exe 所在目录；
3. 如需彻底清除，删除 `%APPDATA%\GuangPanCheckin\`（**会丢失全部打卡记录**，建议先导出备份）。

## 5. 常见问题

### 5.1 启动与窗口

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后什么都没出现 | 程序已在后台运行，第二次双击是"唤起" | 再双击一次；或去托盘区找图标 |
| 找不到托盘图标 | 被 Windows 折叠进 `^` 里 | 点 `^`，把图标拖到外面固定 |
| 提示"程序已经在后台运行" | 同上，且唤起信号没送达 | 托盘右键 → 退出，再重新双击 |
| 双击完全没反应，托盘也没有 | 被安全软件拦截 | 把 exe 加入信任列表，或右键 →「以管理员身份运行」 |
| 关掉窗口后以为退出了 | 关闭按钮是"收进托盘" | 到托盘右键 → 退出 |

### 5.2 提醒相关

| 现象 | 原因与处理 |
|---|---|
| 到点了却不弹 | ① 你已空闲超过阈值（人不在/在看手机）→ 动一下鼠标即弹；② 处于免打扰时段；③ 今天已打满 3 次；④ 勾了"今天不再提醒"→ 到托盘菜单取消 |
| 托盘气泡看不到 | 被专注助手拦截，按 [2.4](#24-通知权限这一步不做提醒可能静默消失) 配置；右下角卡片不受影响 |
| 提醒越来越晚 | 正常：每轮从"弹出时刻"重新数两小时。若长期偏移，说明你到点时不在电脑前，属于设计行为 |
| 看了个视频就没提醒 | "有操作"默认只认 60 秒内的键鼠输入。把「有操作判定」调到 180–300 秒 |
| 升级提醒只响两次就没有了 | 本轮最多 3 响（首提醒 + 2 次升级），之后本轮彻底安静，下一轮会重新开始 |
| 休眠醒来后一堆提醒 | 不会堆积：醒来只判定当前是否过点，补弹一次即止 |

### 5.3 打卡与计数

| 现象 | 原因与处理 |
|---|---|
| 点「我已打卡」被拒绝 | 距离上次不足最小间隔，提示里会写"最早 14:06 才能再打，还要等 1 小时 5 分" |
| 今天想补记一次 | 目前不支持补录历史时间；请在真实打卡时当场点一下 |
| 点错了 | 5 分钟内点「撤销上一条」；超过 5 分钟按钮会变灰（防止误改历史） |
| 跨天后 00:10 打不了 | 「跨天也受最小间隔限制」默认开启（更保险）。若学校口径是按自然日各算各的，到设置里关掉 |
| 计数不对 | 关掉程序，用文本编辑器看 `records.json` 是否被手工改过；被改坏时把 `backups\` 里当天的副本复制回来 |

### 5.4 手机日历

| 现象 | 原因与处理 |
|---|---|
| 手机没响 | 没有给日历 App 通知权限；或导入的是"只读订阅"而非本地日程 |
| 每天响两遍 | 旧日程没删。先删除旧日程，再重新导入新生成的 `.ics` |
| 时间和电脑对不上 | 正常。手机只能按固定时刻响，和电脑的滚动节拍是两套机制 |
| 想完全不用手机日历 | 设置页把那几行"兜底时刻"清空即可（至少保留一行，或直接不导出） |

### 5.5 示意图

| 现象 | 原因与处理 |
|---|---|
| 点「去打卡」没弹图片 | 图片缺失或损坏，程序会提示"点这里重新选"；到设置页重新选一张 |
| 图片很糊 | 程序按宽度 320 等比缩放。换一张分辨率更高的图 |
| 换图失败 | 文件超过 50 MB 或尺寸超过 8000 px，或不是 jpg/png/bmp |

## 6. 注意事项

### 6.1 合规

- 本工具只提供**提醒与记录**，不代替你打卡，不访问小程序接口，不伪造就餐记录。
- 打卡数据以你在小程序里的实际操作为准；本程序的记录是**辅助提醒**，不能作为学校认可的凭证。

### 6.2 数据与隐私

- 程序**不联网**（唯一涉及网络的操作是你自己把 `.ics` 发到手机）；
- 所有数据在 `%APPDATA%\GuangPanCheckin\`，没有云端账户，换机器需手动迁移；
- `app.log` 只记录提醒触发与异常，不含截图、不含聊天内容；
- 每天首次启动自动备份 `records.json` 到 `backups\`，保留最近 30 份。

### 6.3 不要做的三件事

1. **不要移动或删除 exe**：开机自启项记录的是绝对路径，移动后失效，需重新勾选一次「开机自动启动」；
2. **不要手改 `records.json` 里的时间格式**：程序按 ISO8601 解析，格式错了会当作损坏文件备份成 `.bad` 后重建，历史记录可能读不出来；
3. **不要用改系统时间的方式"骗"计数**：程序对时间倒退有保护，会把计时起点拉回当前时间并写日志，容易导致提醒节拍紊乱。

### 6.4 已知边界

| 边界 | 说明 |
|---|---|
| 程序没运行时不会响 | 但启动、开机自启、休眠唤醒时会检查并补提醒 |
| 关机、离开电脑时不会响 | 这部分交给手机日历兜底 |
| 计时起点是"程序观测到的"第一次操作 | 程序没运行的那段时间观测不到；开机自启场景下基本等同真实首次使用 |
| 只能统计"你点了按钮"的记录 | 忘了点按钮就打不上卡，这也是"待办感"的来源 |
| 仅支持 Windows | 没有 macOS / Linux / 手机原生版本 |

## 7. 附录

### 7.1 数据文件说明

```
%APPDATA%\GuangPanCheckin\
├─ records.json     打卡记录（唯一事实来源，切勿手改格式）
├─ settings.json    你的全部设置
├─ runtime.json     当天的计时起点、本轮提醒状态（丢了最多重响一次）
├─ assets\          「去打卡」示意图（target.jpg）
├─ backups\         每日备份，保留 30 份
├─ app.log          运行日志（只在出错/发提醒时写）
├─ guangpan.ics     导出的手机日历
├─ selftest.log     自检结果
└─ uitest.log       界面测试结果
```

`runtime.json` 关键字段：

| 字段 | 含义 |
|---|---|
| `DayStart` | 今天的计时起点（T0） |
| `NextDue` | 本轮到期时间 |
| `RoundStage` | 本轮已弹到第几级（-1 / 0 / 1 / 2） |
| `WaitingForActivity` | 已到点但没人在操作，处于"待弹" |
| `MutedToday` | 今天是否手动静音 |
| `SnoozeUntil` | 点了"10 分钟后再提醒"后的恢复时间 |

### 7.2 自检与排错

```powershell
# 逻辑自检（53 条边界用例：跨天、间隔刚好、无人操作、锁屏、休眠补弹等）
.\光盘打卡提醒.exe --selftest
Get-Content "$env:APPDATA\GuangPanCheckin\selftest.log"

# 界面点击链路（11 条）
.\光盘打卡提醒.exe --uitest

# 确认"有操作"判定真的读到了系统输入（数字应随时间递增）
.\光盘打卡提醒.exe --idle
```
