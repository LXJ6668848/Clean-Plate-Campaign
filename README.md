# 光盘打卡提醒（Clean Plate Campaign）

一个 Windows 托盘小工具：按学校「每日最多 3 次、每次间隔至少 2 小时」的规则提醒你去微信小程序「光盘打卡」打卡，并记录每一次打卡时间。

**它不替你打卡，只负责不让你忘。**

![主面板](docs/images/main.png)

---

## 它解决什么问题

学校要求每天打完 3 次「光盘行动」，难点不在打卡本身：

- 三次时间被**上次实际打卡时间**顶着走，晚打一次后面全部顺延，靠记性算不准；
- 饭点人不在电脑前，或者人在但注意力别处，闹钟响了习惯性划掉；
- 打完又忘了打过没有、上次几点打的。

这个工具把「算下次能打的时间」「在你在电脑前的时候叫你」「把你打过的记下来」三件事接过来。

## 三个核心设计

| # | 设计 | 为什么 |
|---|---|---|
| 1 | **提醒不按固定钟点，按「今天第一次碰电脑」起算** | 固定 12:00 的闹钟，在你 12:40 才打卡时会完全失效。改为 T0 + 2 小时滚动节拍，每弹一次重新数两小时 |
| 2 | **到点先看你在不在** | 读 `GetLastInputInfo` 判断最近 60 秒有没有键鼠输入；人不在就压着，回来动一下鼠标立刻补弹。没人在的闹钟等于没响 |
| 3 | **派生值一律不落盘** | 磁盘只存「打卡记录 + 设置」，次数/下次时间全部实时计算，杜绝「时间改了计数没跟上」的脏状态 |

## 功能一览

- 🕒 今日进度、上次打卡、下次最早可打卡倒计时、**最晚必打安全线**
- 🔔 右下角提醒卡片（不抢焦点、可拖动、120 秒自动收起）+ 提示音 + 托盘气泡
- ⏱ 未处理则 +10 / +30 分钟升级加催，本轮最多 3 响
- ✅ 点按钮时二次校验间隔，不够直接拦下并告诉你还差多久
- ↩️ 5 分钟内可撤销刚打的那一条
- 📷 卡片上的「去打卡」按钮 → 弹出餐盘示意图窗口（可换图）
- 📱 「同步到手机日历」导出 `.ics`，人不在电脑前时的兜底
- 🌙 免打扰时段、手动静音、跨天规则开关、开机自启
- 🔒 不联网、无账号，数据全部在本机 `%APPDATA%\GuangPanCheckin\`

## 快速开始

1. 到 [`release/`](release/) 下载 `光盘打卡提醒.exe`，**放到一个固定目录**（如 `D:\Tools\光盘打卡提醒\`）；
2. 双击运行——免安装、不依赖 .NET 运行时。主面板会直接出现，托盘同时出现圆形图标（可能被折叠进 `^` 里，拖出来固定）；
3. 在小程序里打完卡，回面板点一次「我已打卡」。

图标颜色：**灰蓝** = 等间隔中，**黄** = 可以打卡，**绿** = 今天已打满。

完整说明见 **[docs/使用指南.md](docs/使用指南.md)**：安装配置、通知权限、功能细节、操作步骤、20+ 条常见问题、卸载与数据迁移。

## 技术要点

| 项 | 选择 |
|---|---|
| 语言 / 框架 | C# + .NET 9 WinForms |
| 发布形态 | 单文件自包含 exe（约 46 MB，免装运行时） |
| 存储 | JSON（`records.json` / `settings.json` / `runtime.json`），原子写入 + 每日备份 |
| 活跃判定 | `user32!GetLastInputInfo` 全局最后输入时间 |
| 锁屏/休眠 | `SystemEvents.SessionSwitch` + `PowerModeChanged` |
| 手机兜底 | 生成 RFC 5545 `.ics`（含 VALARM） |

从源码构建（需 .NET 9 SDK）：

```powershell
cd src\GuangPanCheckin
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -o ..\..\release
```

自检：

```powershell
.\release\光盘打卡提醒.exe --selftest   # 53 条边界逻辑用例
.\release\光盘打卡提醒.exe --uitest     # 11 条界面点击链路
.\release\光盘打卡提醒.exe --idle       # 诊断：当前空闲秒数
```

## 边界与说明

- 程序没运行 / 电脑关机时不会响，这部分交给手机日历兜底；
- 计时起点是「程序观测到的」第一次操作，程序未运行的那段时间观测不到；
- 连续看视频、读长文档 60 秒不碰键鼠会被判成「离开」，可在设置里把阈值调到 180–300 秒。

### 关于「自动打卡」

小程序走 `api.clearplate.org.cn` 的私有接口，需要抓包拿 `x-token`，还要复用历史已上传的餐盘图路径。技术上能跑通，但本质是伪造就餐记录，且 token 会随登录态失效、接口随时改版。**本项目故意不做这件事。**
